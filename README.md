# Anime Japanese Listener

TV Japanese audio → laptop microphone → Chrome speech recognition → Gemini → Japanese + romaji + English + grammar breakdown.

## Deploy on Vercel

1. Import this repository into Vercel.
2. In Vercel Project Settings → Environment Variables, add:
   - `GEMINI_API_KEY` = your Gemini API key
3. Redeploy.
4. Open the URL in desktop Chrome.
5. Click **Start listening** and allow microphone access.

The key stays server-side.
